# Unslop Skill
Activation: Runs globally as a background constraint, or explicitly via @unslop or @stop-slop.

## Behavioral Instructions
Strictly sanitize and strip out any generic "AI fluff" from text and documentation outputs.
Ban high-frequency AI buzzwords and corporate jargon like "Delve deep," "In conclusion," "Crucial," "Testament to," "Furthermore," and "Mastery." Keep all technical documentation direct, punchy, active-voice, and straight to the point.
